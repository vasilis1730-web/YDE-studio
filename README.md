# ΥΔΕ Studio — online

Εφαρμογή για νέες παροχές ΔΕΔΔΗΕ, πίνακες, μονογραμμικά σχέδια και έντυπα ΥΔΕ,
με είσοδο χρηστών μέσω **Supabase Auth** και φιλοξενία στο **GitHub Pages**.

Ο κώδικας δεν έχει καμία εξωτερική εξάρτηση κατά την εκτέλεση: η βιβλιοθήκη Supabase
είναι ενσωματωμένη τοπικά στο `vendor/supabase.js`.

## Αρχεία
| Αρχείο | Ρόλος |
|---|---|
| `index.html` | Η σελίδα — δένει τα υπόλοιπα |
| `config.js` | Διεύθυνση Supabase + δημόσιο κλειδί (επιτρέπεται να είναι ορατό) |
| `app.js` | Ο μηχανολογικός πυρήνας (πίνακες, υπολογισμοί, έντυπα) |
| `auth.js` | Είσοδος, ρόλοι, αυτόματη αποσύνδεση, πάνελ χρηστών |
| `vendor/supabase.js` | Βιβλιοθήκη Supabase (τοπικά) |
| `.nojekyll` | Να μην πειράξει το GitHub τα αρχεία |

## Ανέβασμα στο GitHub Pages (3 λεπτά)

1. **Νέο repository** στο GitHub → κουμπί **New**. Όνομα π.χ. `yde-studio`, ορατότητα **Public**, χωρίς README. → **Create repository**.
2. **Ανέβασμα αρχείων:** στη σελίδα του repo → **Add file ▾ → Upload files**. Σύρε **όλα** τα αρχεία αυτού του φακέλου (μαζί με τον φάκελο `vendor`). → **Commit changes**.
3. **Ενεργοποίηση Pages:** **Settings → Pages**. Στο *Source* διάλεξε **Deploy from a branch**, *Branch* = **main**, φάκελος **/ (root)** → **Save**.
4. Μετά από ~1 λεπτό η εφαρμογή είναι ζωντανή στο:
   `https://<το-όνομά-σου>.github.io/yde-studio/`

## Σύνδεση της διεύθυνσης με το Supabase (για επαναφορά κωδικού)
Στο Supabase → **Authentication → URL Configuration**:
- *Site URL*: η διεύθυνση Pages (π.χ. `https://<user>.github.io/yde-studio/`)
- *Redirect URLs*: πρόσθεσε την ίδια διεύθυνση.

## Πρώτη είσοδος
Μπες με **diakolios@rhodes.gr** και τον κωδικό που ήδη έχεις — είσαι **διαχειριστής**.
Από το κουμπί **Χρήστες** (πάνω δεξιά) προσθέτεις μηχανικούς: όνομα, e-mail, προσωρινό
κωδικό, ρόλο. Ο κάθε νέος χρήστης μπαίνει με τον προσωρινό κωδικό και τον αλλάζει από
το κουμπί **Κωδικός**.

## Ρόλοι
- **Διαχειριστής** — όλα + διαχείριση χρηστών.
- **Μηχανικός** — πλήρης χρήση της εφαρμογής.
- **Προβολή μόνο** — βλέπει και εκτυπώνει, δεν επεξεργάζεται.

## Ασφάλεια
- Μόνο ο διαχειριστής δημιουργεί λογαριασμούς (δεν υπάρχει ελεύθερη εγγραφή).
- Απενεργοποίηση χρήστη ανά πάσα στιγμή από το πάνελ.
- Αυτόματη αποσύνδεση μετά από 15′ αδράνειας (ρυθμίζεται στο `config.js`).
- Οι χρήστες του ΥΔΕ είναι **ανεξάρτητοι** από την εφαρμογή Προμηθειών του ίδιου project.
- Προαιρετικά: στο Supabase → Authentication → Policies ενεργοποίησε το
  *Leaked Password Protection* για επιπλέον έλεγχο κωδικών.
